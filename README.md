# 🌐 NetScan Pro

A professional network scanner built with Python.

NetScan Pro helps you discover devices on your local network, scan open ports, and save scan history using a modern cybersecurity-style interface.

---

## 🚀 Features

### Network Scanner

- 🔍 Scan local network devices
- 📡 Detect active IP addresses
- 🖥️ Find device hostnames
- ⚡ Fast multithreaded scanning
- ✅ Online device detection


### Port Scanner

- 🔓 Scan common open ports
- 🌐 Detect running services
- ⚡ Fast port checking


### Database

- 💾 Save scan history
- 📅 Store device information
- 📌 Store port scan results


### Interface

- 🌑 Dark cybersecurity dashboard
- 🖥️ Simple GUI
- ⚡ Fast response

## 🛠️ Technologies Used

- Python
- CustomTkinter
- Socket Programming
- SQLite
- Threading
