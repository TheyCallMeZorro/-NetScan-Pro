# 🌐 NetScan Pro

A professional network scanner built with Python.

NetScan Pro helps you discover devices on your local network, scan open ports, and save scan history using a modern cybersecurity-style interface.

# 🚀 Features

## 🔍 Network Scanner

- Scan local network devices
- Detect active IP addresses
- Find device hostnames
- Fast multithreaded scanning
- Online device detection


## 🔓 Port Scanner

- Scan common open ports
- Detect running services
- Fast port checking
- Service identification


## 💾 Database

- Save scan history
- Store device information
- Store port scan results
- SQLite database support


## 🖥️ Interface

- Modern GUI interface
- Organized scan results
- Fast response

# 🔎 Usage

## Network Scan

Enter your network range:

```
192.168.1.0/24
```

Click:

```
Scan Network
```

The scanner will display:

- IP Address
- Hostname
- Device Status


## Port Scan

Enter target IP:

```
192.168.1.1
```

Click:

```
Scan Ports
```

Results include:

- Port Number
- Service Name
- Status
